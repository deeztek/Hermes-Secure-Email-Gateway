Hermes Secure Email Gateway is **open-core**. The project is licensed under the
**GNU Affero General Public License v3.0 (AGPLv3)**, with a clearly delineated set
of proprietary **Pro Edition** files that are *not* covered by the AGPL.

## Community Edition — AGPLv3

The overwhelming majority of this repository is free and open-source software,
licensed under **AGPLv3** — the full text is in [`LICENSE`](LICENSE). You may use,
study, modify, and redistribute it under the terms of that license, including the
AGPL's network-use source-availability requirement (section 13).

## Pro Edition — proprietary

A limited set of files implement **Pro Edition** features and are **not** covered by
the AGPL. Each such file carries a header that declares, in substance:

> This file is part of Hermes Secure Email Gateway Pro Edition.
> Hermes Secure Email Gateway Pro Edition is NOT free software. It is covered under
> the Hermes Secure Email Gateway Pro Edition License.

Those files are proprietary and governed by the **Hermes SEG Pro Edition EULA**:
<https://docs.deeztek.com/books/hermes-seg-general-documentation/page/hermes-secure-email-gateway-pro-end-user-license-agreement-eula>

## Which license applies to a given file

**The per-file header is authoritative.** If a file's header declares it part of
"Pro Edition," that file is proprietary and the AGPL grant in [`LICENSE`](LICENSE)
does **not** extend to it. Every file *without* such a header is AGPLv3.

Running Community Edition requires no license file. A Pro license is purchased
separately and only affects the proprietary Pro Edition features.

## Third-party components

Bundled third-party libraries and dependencies retain their own upstream licenses,
which are unaffected by the licensing described above.
